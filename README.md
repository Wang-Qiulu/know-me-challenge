# 懂我挑战（Know Me Challenge）

> **朋友之间的小测试：你真的懂我吗？**
>
> 创建 5 道关于自己的题，发给朋友，看他们能答对几道。

---

## 为什么用户用完后会主动疯狂转发？

### 整体理念

「懂我挑战」的设计核心不是"鼓励转发"，而是**让转发成为产品体验的必经环节，而不是可选的额外动作**。

传统产品的"转发"是用户完成行为后的"出口"——做完了就走，转发可有可无。本产品从结构上把"转发"重新设计成**循环的入口**——每个用户既是答题者，也是出题者；每次转发不是终点，而是下一轮传播的起点。

### 产品如何促进用户疯狂转发

**1. 零摩擦参与（降低"我要不要点开"的犹豫）**

- 无需注册，点开链接即玩
- 5 道题 / 1-2 分钟，匹配"碎片时间随手玩"的传播节奏
- 移动端优先，贴合微信/微博/小红书的分享场景

**2. 强情绪反馈（创造"我必须告诉别人"的动机）**

- 6 档趣味称号（灵魂挚友 / 心有灵犀 / 最熟悉的陌生人...）
- 高分是"社交货币"（炫耀默契），低分是"自嘲素材"——**两种结果都想分享**
- 答案揭晓时"他居然答对了"的惊喜，是最强的情绪触发

**3. 双向角色 + 裂变循环（让"转发"不是选择、是必然）**

- 答完题的用户，1 步即可创建自己的挑战
- 每个用户既是答题者，也是出题者
- 形成经典 viral loop：**创建 → 邀请 → 答题 → 创建**

**4. 内置分享话术（消灭"我该怎么介绍"的负担）**

- 4 套营销文案模板（挑战型 / 邀请型 / 好奇型 / 玩味型），随机切换
- 复制即用，零文案创作门槛
- 让"描述这个产品"不再是传播障碍

**5. 公开排行榜（激发好友间的社交比较）**

- 所有成绩可查、可比较
- "朋友得了几分"成为新话题 → 二次传播动力
- 朋友间形成"再来挑战一次"的良性竞争

**6. 题目本身的社交价值**

- 5 道题是创建者真实偏好的载体
- "我就是这样出题来测你的"本身就是一个值得聊的话题
- 鼓励好友之间相互"出题测我"，形成微型社交事件

### 闭环示意

```
用户A 创建挑战
   ↓ 发邀请链接
用户B/C/D 答题 → 看到成绩 + 称号
   ↓ 一键 "我也创建自己的"
用户B 变成新的创建者
   ↓ 发新一轮邀请链接
用户E/F/G 答题
   ↓ 循环继续
```

**核心结论**：本产品的每个用户都"被迫"既是消费者，又是创造者。转发不是营销诉求，而是产品结构上的必然路径——你玩完了，你就自然成为下一个传播节点。

## 这是什么？

一款**轻量级的熟人答题小程序**。你出 5 道关于自己的单选题（"我最喜欢的电影是？"），写下你的真实答案，然后把链接发给朋友。他们答完会拿到一个分数和有趣的称号（比如"灵魂挚友"或"最熟悉的陌生人"），同时你也能在后台看到排行榜，知道谁最懂你。

整个过程不需要注册账号，点开链接就能玩。

## 怎么玩？

### 📝 创建挑战（30 秒）

1. 打开 [懂我挑战](https://qiululog.cyou) → 点"创建你的挑战"
2. 已经有 5 道默认题目，你可以根据需要修改题目和选项，也可以使用默认题目快速开始
3. 每道题选一个**你的真实答案**（这是朋友猜对的标准）
4. 点发布 → 拿到**邀请链接**（发给朋友）和**管理链接**（自己保管）

### 📩 邀请朋友

- 把邀请链接通过微信、QQ 等发给朋友
- 朋友点开 → 输入昵称 → 答 5 道题 → 立刻看到分数和称号

### 🎉 查看成绩

- 答完题的朋友会拿到"灵魂挚友""心有灵犀""半知己""普通朋友""点头之交""最熟悉的陌生人"中的一个称号
- 每个人可以把自己的成绩发给创建者
- 创建者打开管理链接就能看到所有朋友的成绩排行榜

### 🔐 管理你的挑战

- 改标题、关闭挑战、删除挑战，都通过管理链接操作

## 主要功能

| 功能            | 说明                                   |
| --------------- | -------------------------------------- |
| 🎯 5 道默认题目 | 直接改就能用，不用从零开始             |
| 📊 自动计分     | 后端算分，前端永远看不到正确答案       |
| 💬 趣味称号     | 6 个称号，根据分数自动匹配             |
| 🏆 排行榜       | 所有人成绩排名，同分并列               |
| 🔗 一键分享     | 复制文案 + 链接，配有 4 种营销话术模板 |
| 🌙 移动优先     | 专为手机设计，平板和桌面也能用         |
| ⚡ 无需注册     | 点链接即玩，保护隐私                   |
| 🛡️ 防作弊       | 同一朋友只能正式答一次                 |

## 技术栈

- **前端**：React 18 + TypeScript + Vite + Tailwind CSS
- **后端**：Supabase（Postgres 数据库 + Edge Functions）
- **部署**：Vercel（前端）+ Supabase Cloud（后端）
- **包管理**：pnpm 10（monorepo 风格）

## 🛠️ 本地开发

### 环境要求

- Node.js >= 20
- pnpm >= 10（推荐 `corepack enable`）

### 启动步骤

```bash
# 1. 克隆 + 安装依赖
git clone https://github.com/Wang-Qiulu/know-me-challenge.git
cd know-me-challenge
pnpm install

# 2. 配置环境变量
cp apps/web/.env.example apps/web/.env.local
# 在 .env.local 里填入 Supabase 的 URL 和 anon key

# 3. 启动开发服务器
pnpm dev

# 浏览器打开 http://localhost:5173
```

### 常用命令

| 命令             | 作用                           |
| ---------------- | ------------------------------ |
| `pnpm dev`       | 启动开发服务器                 |
| `pnpm build`     | 生产构建（含 TypeScript 检查） |
| `pnpm lint`      | 代码风格检查                   |
| `pnpm typecheck` | TypeScript 类型检查            |
| `pnpm format`    | 自动格式化代码                 |
